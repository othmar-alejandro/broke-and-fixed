Top priorities found:
1. Compliance/local-trust risk: public SERP/local card says “Building contractor”; site copy includes contractor/licensed wording in several articles.
2. Hard claims/legal/cost hooks need owner-approved source-of-truth review (permit, price/timeline, project count/response claims).
3. Spanish localization incomplete: /es H1 and many ES metadata/gallery strings include English; crawl found 62 ES pages with obvious English in title/desc/H1 fields.
4. Hreflang missing x-default on 56 EN/ES service/location/index pages.
5. Mobile performance issue: Lighthouse mobile /en performance 36, LCP 7.7s, TBT 3,330ms; large logo/unused JS/third-party scripts flagged.
6. Metadata overlong/duplicated: 131 titles >60 chars, 223 descriptions >160 chars, 6 duplicate descriptions.
7. Gallery/project proof pages are thin and some ES gallery copy remains English.

Limits: Search Console, analytics, GBP owner dashboard, and Firecrawl web search API were unavailable, so traffic/index/query/conversion metrics remain unverified.
