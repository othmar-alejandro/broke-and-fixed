# Image Generation Prompts — Phase 3.2 Hyperlocal Pillar Pages

Per the CLAUDE.md image rule: each pillar page wants a hero plus at least one in-body
image, with descriptive, keyword-rich filenames and alt text (service + location).
Drop generated files at the exact path listed. Photorealistic, high-end architectural
photography. South Florida / Miami-Dade context. Natural daylight. No text, no logos,
no watermarks, no close-up faces. Hero: 1600x900 (16:9). In-body: 1600x900.
Brand feel: premium but accessible, warm neutrals, real (not stocky/oversaturated).

> Wiring note: the service x location pages currently render a shared per-service
> hero and gallery. Once these location-specific files exist, they can be wired into
> the pillar entries as a small follow-up so each pillar shows its own imagery.
